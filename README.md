# Learning SDL3 GPU

- Following this tutorial: https://www.youtube.com/playlist?list=PLI3kBEQ3yd-CbQfRchF70BPLF9G1HEzhy
- Implemented up to Part `13.3`
- Models are Kenney's
- Code structure is loosely based on the tutorial, most my own.
- Simple built manager that can toggle builds between DX12 and Vulkan, and create several profiles (dev, debug, release ...)
- Only tested on Windows 11
- Requires `shadercross` to be in PATH
- Run code with `build.bat -run`, see `build.bat help` for options
- **No AI** was used
